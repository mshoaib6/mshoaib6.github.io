# muhammad-shoaib.com

Personal academic homepage. Static HTML served by GitHub Pages from the
`master` branch; `.nojekyll` disables the Jekyll build.

```
index.html          the page
css/light.min.css   Bahunya classless base framework
css/index.css       site styles
images/             profile photo and favicons
CNAME               custom domain
```

Run locally:

```sh
python3 -m http.server 8000
```

The previous AcademicPages/Jekyll site is in this repository's git history.
